Introduction to Encryption

Encryption converts data into unreadable form using math. Two main types:

  • Symmetric — one key for encrypt and decrypt. Fast. Example: AES.
  • Asymmetric — public key encrypts, private key decrypts. Example: RSA.

AES-128

AES (Advanced Encryption Standard) — symmetric block cipher, NIST standard since 2001. Encrypts 128-bit blocks with 128-bit key.

How it works

  • Data split into 4x4 byte blocks (128 bits)
  • 10 rounds of transformations per block
  • SubBytes — byte substitution via S-Box
  • ShiftRows — cyclic row shifts
  • MixColumns — column mixing in GF(2^8)
  • AddRoundKey — XOR with round key

Implementation

  • Password to key via PBKDF2-HMAC-SHA256 (10000 iterations)
  • Random salt (16 bytes) per encryption
  • ECB mode with PKCS#7 padding

Spec: FIPS 197 — csrc.nist.gov/pubs/fips/197/final

RSA-2048

Asymmetric encryption by Rivest, Shamir, Adleman (1977). Security based on difficulty of factoring large numbers.

Key Generation

  • Two primes p and q (1024 bits each)
  • Modulus n = p x q (2048 bits)
  • Euler totient phi(n) = (p-1)(q-1)
  • Public exponent e = 65537
  • Private exponent d = e^(-1) mod phi(n)

Encrypt / Decrypt

  • Encrypt: c = m^e mod n
  • Decrypt: m = c^d mod n
  • Messages split into 223-byte blocks

Spec: RFC 8017 — rfc-editor.org/rfc/rfc8017

SHA-256

Cryptographic hash from SHA-2 family. Converts any data to 256-bit hash. Used in HMAC and PBKDF2.

  • 512-bit blocks, 64 compression rounds
  • AND, OR, XOR, NOT and bit shifts
  • One-way: cannot recover original data from hash

Spec: FIPS 180-4 — csrc.nist.gov/pubs/fips/180-4
