Общие сведения о шифровании

Шифрование — процесс преобразования данных в нечитаемый вид. Существует два основных вида:

  • Симметричное — один ключ для шифрования и расшифрования. Быстрое. Пример: AES.
  • Асимметричное — публичный ключ шифрует, приватный расшифровывает. Пример: RSA.

AES-128

AES (Advanced Encryption Standard) — симметричный блочный шифр, стандарт NIST с 2001 года. Шифрует блоками 128 бит с ключом 128 бит.

Как работает

  • Данные разбиваются на блоки 4x4 байта (128 бит)
  • Каждый блок проходит 10 раундов преобразований
  • SubBytes — замена байт по таблице S-Box
  • ShiftRows — циклический сдвиг строк матрицы
  • MixColumns — перемешивание столбцов в GF(2^8)
  • AddRoundKey — XOR с раундовым ключом

Особенности реализации

  • Пароль -> ключ через PBKDF2-HMAC-SHA256 (10000 итераций)
  • Случайная соль (16 байт) для каждого шифрования
  • Режим ECB с PKCS#7 padding

Спецификация: FIPS 197 — csrc.nist.gov/pubs/fips/197/final

RSA-2048

RSA — асимметричный алгоритм (Rivest, Shamir, Adleman, 1977). Безопасность основана на сложности факторизации больших чисел.

Генерация ключей

  • Два больших простых числа p и q (по 1024 бита)
  • Модуль n = p x q (2048 бит)
  • Функция Эйлера phi(n) = (p-1)(q-1)
  • Публичная экспонента e = 65537
  • Приватная экспонента d = e^(-1) mod phi(n)

Шифрование / расшифрование

  • Шифрование: c = m^e mod n
  • Расшифрование: m = c^d mod n
  • Длинные сообщения разбиваются на блоки по 223 байта

Проверка простоты

Тест Миллера-Рабина (20 раундов). Вероятность ошибки менее 2^(-40). Предварительная фильтрация первыми 170 малыми простыми.

Спецификация: RFC 8017 — rfc-editor.org/rfc/rfc8017

SHA-256

Криптографическая хеш-функция SHA-2. Преобразует данные любой длины в 256-битный хеш. Используется в HMAC и PBKDF2.

  • Блоки по 512 бит, 64 раунда сжатия
  • Операции AND, OR, XOR, NOT и битовые сдвиги
  • Необратима: нельзя восстановить исходные данные из хеша

Спецификация: FIPS 180-4 — csrc.nist.gov/pubs/fips/180-4
